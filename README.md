# Basic Version Control System

A Bash implementation of a small version-control system named BVCS. It supports repository initialization, staging files, commits, status inspection, logs, diffs, restoration, and automated specification tests.

## Usage

```bash
chmod +x 2205006.sh
./2205006.sh init
./2205006.sh help
```

Run the test suite with:

```bash
./test_bvcs.sh ./2205006.sh
```
